## Règles de lecture

- **Obligatoire** : imposé par un texte cité. **Conditionnel** : obligatoire dans le cas indiqué. **Recommandé** : conseillé par un texte, sans obligation. **Usage, non sourcé** : pratique courante, sans texte.
- **Confiance** : « Lu sur Légifrance » seulement après lecture effective de la page officielle. Une mention reste à revérifier tant qu'elle est en « Extrait de recherche » ou « Source secondaire ».
- Une mention n'est rendue bloquante dans l'application que si elle est « Obligatoire » ou « Conditionnel » et « Lu sur Légifrance ».
